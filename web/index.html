FEATURES

特性Features

骨架管稳定，契约管边界，模块管能力——每一件都围绕「内核不做模块的事，模块碰不到内核的里子」展开。The skeleton keeps things stable, contracts keep boundaries, modules bring capabilities — built on one principle: the kernel never does a module's job, and a module never touches the kernel's internals.

模块化内核Modular kernel

核心五件（session / loop / tool / provider / kernel）+ 零依赖契约包 @orosus/contracts。模块经拓扑序激活、可热重载、失败降级不阻断启动。Five core pieces (session / loop / tool / provider / kernel) + the zero-dependency contracts package @orosus/contracts. Modules activate in topological order, hot-reload, and fail soft without blocking startup.

多厂商支持Multi-provider

自定义厂商统一入口（OpenAI 兼容端点）+ /provider 交互式向导 + 内置厂商目录（端点 / 模型 / 思考档位），运行期 /model /effort 即切。A unified custom-endpoint entry (OpenAI-compatible) with an interactive /provider wizard and a built-in vendor catalog; switch at runtime with /model and /effort.

子代理Subagents

模型经委派工具开子会话并行干活：前台以 agent 组展示、后台任务完成自动送回，孙代理隔代嵌套；/tasks 查看与应答审批；轮数 / 不活动 / 总时长三道保险丝，撞限走收尾轮交卷不硬断。The model delegates into parallel sub-sessions: foreground ones render as agent groups, background ones report back when done, grandchildren nest one level. /tasks lists them and answers approvals; three fuses end runaways with a wrap-up turn instead of a hard cut.

会话感知与共享记忆Peer awareness & shared memory

同项目会话互相看见——占用查询 / 认领 / 释放防止并行会话撞车；跨会话共享记忆库（写 / 列 / 读），/tool-peers__memory 浏览窗；Claude Code / ZCode / qwen-code / codex / DeepSeek-Reasonix 五家既有记忆一键导入。Sessions in the same project see each other — occupancy queries, claims and releases keep parallel sessions from colliding; a shared memory store (write / list / read) crosses sessions, browsable via /tool-peers__memory; one-click import from existing Claude Code / ZCode / qwen-code / codex / DeepSeek-Reasonix memories.

技能系统Skill system

一个目录一份 SKILL.md 纯知识——四轨目录（用户 / 项目 × 通用 / 品牌）扫描，同名项目压用户；模型按需加载，用户走斜杠菜单技能区；/settings 里 Alt+K 启停；出厂自带十一件。One SKILL.md per directory, pure knowledge — four search tracks (user/project × generic/brand), project overrides user; the model loads on demand, users load via the slash-menu skill section; toggle with Alt+K in /settings; eleven factory skills included.

钩子系统Hooks

七事件生命周期 shell 钩子，协议与 Claude Code 兼容、现成脚本零改动可跑：拦截危险命令、自动放行安全命令、往上下文注入项目知识、完成时通知；项目层钩子 sha256 信任门 + 注入三道闸；/settings → 钩子 管理、Ctrl+H 看注入。Lifecycle shell hooks on seven events, protocol-compatible with Claude Code — existing scripts run unchanged: block risky commands, auto-approve safe ones, inject project knowledge, notify on completion; project-level hooks pass a sha256 trust gate plus a three-layer injection guard; manage in /settings → Hooks, inspect injections with Ctrl+H.

联网能力Web access

Web 搜索与抓取：原生搜索协议面 / Tavily / Brave 多后端自动遍历，零配置即可起搜；抓取的网页进上下文窗口化管理。Web search & fetch: native-search protocol faces / Tavily / Brave backends traversed automatically — searches work with zero configuration; fetched pages enter windowed context management.

多媒体Multimedia

Alt+V 贴图、图 / 视频文件读取真实喂模型；降采样 / 裁剪 / 转码 / 视频剪辑工具族读前控上下文成本；视觉模型通道给非多模态模型代看图。Paste images with Alt+V or feed image / video files to the model directly; downsample / crop / convert / video-clip tools keep context costs down before reads; a vision-model channel lets non-multimodal models see images too.

工具生态Tool ecosystem

文件系统、Shell（工作目录记忆 + 后台作业）、Todo、Ask 内置工具；Goal 长任务续跑三工具；ToolSearch 大工具集按需检索；MCP 桥接（出厂预装 + /settings 管理面）。工具强制两阶段：声明（无副作用）→ 执行（唯一副作用点）。Built-in modules for filesystem, shell (working-directory memory + background jobs), todo and ask; a Goal trio for long-running task continuation; ToolSearch for on-demand lookup in large tool sets; an MCP bridge (factory presets + management in /settings). Every tool is strictly two-phase: declare (no side effects) → execute (the only side-effect point).

审批门Approval gate

tool/pre-execute 瀑布拦截点统一审批；三档模式（每次都询问 / 需要时候询问 / 从不询问），手写 deny 规则始终优先。One unified approval waterfall at tool/pre-execute; three modes (ask-every-time / ask-when-needed / never-ask); handwritten deny rules always win.

上下文管理Context management

自动 / 手动压缩（compaction 模块），read 窗口化 + 截断去重，压缩摘要 Ctrl+O 全屏回看；多模态图片真实喂图。Automatic and manual compaction, windowed reads with truncation dedup, full-screen Ctrl+O summary review, real multimodal image feeding.

会话树Session tree

/fork 分叉落盘成树——/session-tree__view 全屏看树跳枝、/session-tree__branch 在任意节点建新枝，项目内封闭。/fork forks persist as a tree — view and jump branches with /session-tree__view, branch at any node with /session-tree__branch, scoped to the project.

TUI 界面TUI

全屏接管、流式重绘、Markdown 渲染（表格 / 代码高亮 / LaTeX）；键盘 + 鼠标双操作面——滚轮滚动、拖选即复制、双击选词 / 三击选行、URL 单击打开、滚动条；历史懒分页回看，Alt+E / O / F / S 分级折叠（思考块 / 工具明细 / 失败详情 / 前序步骤）。Full-screen takeover, streaming repaint, Markdown rendering (tables / code highlighting / LaTeX) — keyboard and mouse both work: wheel scrolling, drag-select copies, double-click selects words, click opens URLs, scrollbar included; lazy-paged history and tiered folding with Alt+E / O / F / S (thinking / tool details / error details / earlier steps).

数据自治理Data self-governance

会话 JSONL 可读可 grep；OROSUS_HOME 环境变量 + orosus home migrate 支持整体迁移缓存目录；模块配置 modules.d/ 每模块一文件。Session JSONL stays human-readable and grep-able; OROSUS_HOME plus orosus home migrate relocates the data directory wholesale; module configs live one-file-per-module under modules.d/.

开放扩展Open extension

往 .orosus/modules/ 放一个 TS 文件就是模块——jiti 直接吃源码，不用构建不用发包；首挂确认信任门 + 声明面清单防投毒。Drop a TS file into .orosus/modules/ and it's a module — jiti runs the source directly, no build, no publish; a first-mount trust gate with a declared-surface list guards against poisoning.

QUICKSTART

三分钟上手Up and running in three minutes

克隆即用——首次启动若没有可用 provider，会自动进入 /provider 向导，按菜单引导完成配置后自动 reload。Clone and go — on first launch with no provider configured, the /provider wizard walks you through setup and reloads automatically.

git clone https://github.com/zhangxyfs/Orosus.git
cd Orosus
pnpm install

pnpm orosus

3 · 日常使用Daily use

直接输入自然语言对话；/ 开头是命令（输入即弹菜单，技能区殿后），@ 引用文件——输入即弹目录菜单逐级选择（支持 @path#L10-L20 行范围），Alt+V 粘贴图片，Alt+Enter / Shift+Enter 换行，Ctrl+O 回看压缩摘要，Ctrl+P 模块总览，滚轮直接滚动对话。Chat in plain language; / commands (a menu pops up as you type, skills at the bottom), @ file references via a directory menu that opens as you type (line ranges like @path#L10-L20), Alt+V to paste images, Alt+Enter / Shift+Enter to break the line, Ctrl+O for compaction summaries, Ctrl+P for the module launcher, and the mouse wheel scrolls the conversation.
