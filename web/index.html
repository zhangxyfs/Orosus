FEATURES

特性Features

骨架管稳定，契约管边界，模块管能力——每一件都围绕「内核不做模块的事，模块碰不到内核的里子」展开。The skeleton keeps things stable, contracts keep boundaries, modules bring capabilities — built on one principle: the kernel never does a module's job, and a module never touches the kernel's internals.

模块化内核Modular kernel

核心五件（session / loop / tool / provider / kernel）+ 零依赖契约包 @orosus/contracts。模块经拓扑序激活、可热重载、失败降级不阻断启动。Five core pieces (session / loop / tool / provider / kernel) + the zero-dependency contracts package @orosus/contracts. Modules activate in topological order, hot-reload, and fail soft without blocking startup.

多厂商支持Multi-provider

Anthropic / GLM / Kimi / DeepSeek / OpenAI 品牌适配器 + 自定义厂商统一入口（OpenAI 兼容端点），运行期 /model 即切。Brand adapters for Anthropic / GLM / Kimi / DeepSeek / OpenAI plus a unified custom-endpoint entry (OpenAI compatible); switch anytime with /model.

工具生态Tool ecosystem

文件系统、Shell、Todo、Ask 内置工具模块；技能系统与 MCP 桥接。工具强制两阶段：声明（无副作用）→ 执行（唯一副作用点）。Built-in tool modules for filesystem, shell, todo and ask; a skill system and an MCP bridge. Every tool is strictly two-phase: declare (no side effects) → execute (the only side-effect point).

审批门Approval gate

tool/pre-execute 瀑布拦截点统一审批；ask-when-needed / yolo / auto 多档模式，手写 deny 规则始终优先。One unified approval waterfall at tool/pre-execute; ask-when-needed / yolo / auto modes; handwritten deny rules always win.

上下文管理Context management

自动 / 手动压缩（compaction 模块），read 窗口化 + 截断去重，多模态图片真实喂图。Automatic and manual compaction (the compaction module), windowed reads with truncation dedup, real multimodal image feeding.

TUI 界面TUI

全屏接管、流式重绘、键盘菜单 / Esc 取消、Markdown 渲染（含 LaTeX），连山主题十色贯穿始终。Full-screen takeover, streaming repaint, keyboard menus with Esc, Markdown rendering (LaTeX included) — all in the ten-color Lianshan theme.

数据自治理Data self-governance

会话 JSONL 可读可 grep；OROSUS_HOME 环境变量 + orosus home migrate 支持整体迁移缓存目录。Session JSONL stays human-readable and grep-able; OROSUS_HOME plus orosus home migrate relocates the data directory wholesale.

开放扩展Open extension

往 .orosus/modules/ 放一个 TS 文件就是模块——jiti 直接吃源码，不用构建不用发包；项目级信任门防投毒。Drop a TS file into .orosus/modules/ and it's a module — jiti runs the source directly, no build, no publish; a project-level trust gate guards against poisoning.

QUICKSTART

三分钟上手Up and running in three minutes

克隆即用——首次启动若没有可用 provider，会自动进入 /provider 向导，按菜单引导完成配置后自动 reload。Clone and go — on first launch with no provider configured, the /provider wizard walks you through setup and reloads automatically.

1 · 安装Install 
git clone https://github.com/zhangxyfs/Orosus.git
cd Orosus
pnpm install
2 · 启动Launch 
pnpm orosus

无 provider 时自动进配置向导。Opens the config wizard when no provider is set.
