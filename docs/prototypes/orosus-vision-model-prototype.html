钉死（2026-09-30 用户口令）

  • 两入口：/settings 新项「配置视觉模型」+ 首启引导插页（网络搜索页之前——现流程已四页〔m5b 消息备份为第 4 页〕，插入后为 第 3 / 5 页；版式照 onboarding 原型真 modal 族：居中弹窗 + 背板 + 引导期双栏背景）。
  • 三选项：停用（默认）/ 自动（用已配置模型里支持图片的）/ 指定模型（多模态过滤列表）。
  • 指定模型空态：无可选时 toast 指路 /provider 配置多模态模型。
  • 引导页可跳过：不选任何模型直接 Ctrl + N = 不开启（默认）。
  • settings 列表实机形态：行首 ● 点（accent）+ 标题白 + 说明灰；标题栏右侧 1/2 分页计数；键位行含 PgUp/PgDn 翻页；清单平铺无分隔行（SETTINGS_ITEMS 同源）。
  • 设置侧弹窗为 dock 形态：贴输入框上缘、与输入框同宽（skill 详情窗同款）；引导侧是居中 modal 族——两族各按其规。
  • 列表恒定 5 行：模型列表区恒留 5 行空间，不足补空行、空槽留白（浮层高度恒定防闪烁铁律）；过滤说明行与「暂不启用」行在固定区之外。

待拍板

  • 自动档取哪个：已配置模型里多个 vision 时——建议取列表第一个（原型注记「取第一个」），或取「最近用过的」。
  • 落盘键形态：建议单键三态 [media] visionModel = "off" | "auto" | "<槽/模型>"（缺省 = off）。
  • 选中模型失效时（槽被删 / 目录查实非 vision）：建议启动时 warn 一条 + 当作未配置回落，不硬炸。
  • 引导第 2 页跳过时（无任何提供商）：本页仍显示空态（流程可预期），还是直接跳过本页——建议显示空态。
  • settings 项位置：原型排在「配置网络搜索」之前（与引导顺序一致）——可调。
